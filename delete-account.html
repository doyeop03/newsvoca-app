NEWSVOCA

계정 및 데이터 삭제 안내

NEWSVOCA 계정 삭제를 원하는 사용자는 앱에서 직접 삭제하거나 카카오톡 문의 채널을 통해 삭제를 요청할 수 있습니다.

1. 앱에서 직접 삭제

NEWSVOCA 앱에 로그인한 뒤 다음 순서로 계정 삭제를 진행할 수 있습니다.

  1. 앱에서 마이페이지를 엽니다.
  2. 계정 삭제를 선택합니다.
  3. 화면의 안내에 따라 본인 확인과 삭제 확인을 완료합니다.

계정 삭제가 완료되면 해당 계정과 연결된 사용자 학습 데이터 및 Firebase Authentication 계정이 삭제됩니다. 삭제된 정보는 복구할 수 없습니다.

2. 문의를 통한 삭제 요청

앱에 로그인할 수 없거나 앱 내 삭제가 어려운 경우 아래 카카오톡 문의 채널에서 NEWSVOCA 계정 삭제를 요청할 수 있습니다.

카카오톡 문의하기

계정 확인을 위해 가입 이메일 등 최소한의 계정 식별 정보를 요청할 수 있으며, 비밀번호는 요구하지 않습니다.

3. 삭제되는 데이터

계정 삭제가 정상적으로 완료되면 다음 데이터가 삭제됩니다.

  • Firebase Authentication 계정
  • 이메일, UID 등 사용자 계정 식별 정보
  • 저장한 단어와 학습한 단어 기록
  • 정답 및 오답 기록
  • 복습 단계 및 복습 일정
  • 퀴즈 점수 및 완료 기록
  • 기사 학습 기록
  • 사용자별 학습 현황 데이터
  • NEWSVOCA의 사용자별 Cloud Firestore 데이터
  • 기기 또는 브라우저에 저장된 NEWSVOCA 로컬 설정 및 학습 상태

4. 보관되는 데이터

NEWSVOCA는 계정 삭제 후 별도의 사용자 학습 데이터 보관 기간을 두고 있지 않습니다.

뉴스 기사 기반 학습 콘텐츠, 공지, 법적 고지 등 모든 사용자에게 제공되는 공용 서비스 데이터는 특정 사용자의 계정 데이터가 아니므로 계정 삭제 대상에 포함되지 않습니다.

5. 처리 과정 안내

앱 내 삭제는 본인 확인 후 앱의 계정 삭제 기능을 통해 처리됩니다. 문의를 통한 요청은 계정 소유자 확인과 대상 계정 식별 절차를 거쳐 처리됩니다.

자세한 개인정보 처리 내용은 NEWSVOCA 개인정보처리방침에서 확인할 수 있습니다.
